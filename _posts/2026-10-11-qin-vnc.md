在 `qin` 上用 **TigerVNC + XFCE** 开桌面。会话只监听本机，必须经 **SSH（或 Tailscale）隧道** 连接。

## 常用命令

| 命令 | 作用 |
|---|---|
| `vncstart` | 找空闲 `:1`–`:99`，本机监听，默认 **7 天**到期 |
| `vncstart long` | 同上，最长 **60 天** |
| `vncstart 14d` | 指定寿命（也可用 `7d` / `2w` / `1m`） |
| `vncstart -geometry 1920x1080` | 指定分辨率 |
| `vnckill :N` | 关掉 `:N` 并清到期标记 |
| `vncserver -list` / `vncwhich` | 查看会话与端口 |
| `vncuse N` | 当前 shell 设置 `DISPLAY=:N.0` |
| `vncpasswd` | 设置 VNC 密码（仅前 8 位有效） |

快捷分辨率：`vncsmall`（1440×900）、`vnc4k`、`vncv`、`vncv2`。

## 显示号与端口

显示号 `:N`，RFB 端口 `5900+N`。

| 显示 | 端口 | 说明 |
|---|---|---|
| `:1` / `:2` | 5901 / 5902 | systemd 映射，勿动 |
| `:3` | 5903 | xcshen 的 systemd 单元 |
| `:4` | 5904 | 常用额外会话 |
| `:7` | 5907 | 他人占用，**不要用** |

## 笔记本连接

```bash
ssh -N -L 5904:127.0.0.1:5904 xcshen@HOST
# 查看器连 localhost:4 或 127.0.0.1:5904，用 VncAuth
```

`HOST` 用你平时的路径（如 ali 反代或 Tailscale）。不要改 sshd / 防火墙来“修”VNC，走隧道即可。

## 注意

- 不要杀别人的 `Xvnc`，不要抢 `:7`。
- 失败登录过多会锁会话，需以属主身份重启该显示。
- GUI（IDL、matplotlib 等）先 `vncwhich`，再 `vncuse N`。
