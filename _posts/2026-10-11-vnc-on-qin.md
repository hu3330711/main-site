How to start, list, and stop desktop sessions on `qin`, plus the words that show up in the commands.

VNC here is **TigerVNC**. The desktop is **XFCE** (`startxfce4` in `~/.vnc/xstartup`). Sessions listen on **localhost only**, so you always connect through an SSH (or Tailscale) tunnel.

## Everyday commands

Use these from a login shell on qin (`~/.bashrc` plus `/etc/profile.d/vnc-helpers.sh`).

| Command | What it does |
|---|---|
| `vncstart` | Pick a free display `:1`–`:99`, start VNC with `-localhost yes`, default lifetime **7 days** |
| `vncstart long` | Same, lifetime **60 days** (maximum) |
| `vncstart 14d` | Lifetime 14 days (`7d`, `2w`, `1m` also work) |
| `vncstart -geometry 1920x1080` | Start with a given pixel size |
| `vnckill :N` | Stop display `:N` and drop its expire stamp (`vnckill 4` also works) |
| `vncserver -list` | List this user's TigerVNC sessions (display and PID) |
| `vncwhich` | Print `DISPLAY`, running `Xvnc` displays, and live TCP viewers on ports 5900–5999 |
| `vncuse N` | `export DISPLAY=:N.0` for GUI programs in this shell |
| `vncpasswd` | Set or change the VNC password (8-character DES key in `~/.vnc/passwd`) |

Geometry shortcuts (all call `vncstart`):

| Alias | Geometry |
|---|---|
| `vncsmall` | 1440×900 |
| `vnc4k` | 3840×2160 |
| `vncv` | 1890×3360 (tall) |
| `vncv2` | 1080×1920 (phone/portrait) |

Typical session:

```bash
vncstart -geometry 1920x1080
# → VNC started on :4 (port 5904), stops at YYYY-MM-DD HH:MM (7 days)

vncserver -list
vncwhich

vnckill :4
```

## Display, port, and reserved numbers

A **display** is `:N`. The RFB **port** is `5900 + N`. The X11 port is `6000 + N`.

| Display | Port | Owner | Notes |
|---|---|---|---|
| `:1` | 5901 | root | systemd mapping; do not use |
| `:2` | 5902 | qin | systemd mapping; do not use |
| `:3` | 5903 | xcshen | systemd `vncserver@:3` (currently failed; extra sessions use `vncstart`) |
| `:4` | 5904 | xcshen | extra session, localhost; often the live desktop |
| `:7` | 5907 | jhzhang | **do not start as xcshen** |

`vncstart` skips a number if port 590N, port 600N, an `Xvnc :N` process, or `/tmp/.X11-unix/XN` is already in use. It then runs:

```bash
vncserver :N -localhost yes [your extra options]
```

and writes `~/.vnc/expire-N.stamp`. `/usr/local/sbin/vnc-lifetime-sweep` (systemd `vnc-lifetime.service`) kills the session when the stamp expires.

## `vncserver` (low level)

TigerVNC still ships `/usr/bin/vncserver`. Distro notes say systemd `vncserver@:N` replaced the wrapper for mapped displays; on qin, **manual sessions still go through `vncserver` via `vncstart`**.

```bash
vncserver :4 -localhost yes -geometry 1920x1080
vncserver -list
vncserver -kill :4
```

Useful options (passed through `vncstart` after the lifetime token):

| Option | Meaning |
|---|---|
| `-localhost yes` | Bind 127.0.0.1 only (required on qin) |
| `-geometry WxH` | Desktop size in pixels |
| `-depth 24` | Color depth |
| `-SecurityTypes VncAuth` | Classic VNC password only (no VeNCrypt/TLS) |
| `-name qin:4` | Window title on the viewer |
| `-kill :N` | Stop that display |
| `-list` | Show sessions |

Do not pass `long` / `14d` to raw `vncserver`; those tokens belong to `vncstart`.

## systemd mapped sessions

`/etc/tigervnc/vncserver.users` maps `:1=root :2=qin :3=xcshen :7=jhzhang`.

```bash
systemctl status vncserver@:3
# enable at boot (root): systemctl enable --now vncserver@:3
```

A mapped unit and a `vncstart` session cannot share the same `:N`. Prefer `vncstart` for extra desktops (`:4`, `:5`, …). Do not start `:7`.

## Password and files

```bash
vncpasswd                 # prompt; writes ~/.vnc/passwd (mode 600, 8 bytes)
```

Classic VNC auth uses only the **first 8 characters**. This is the VNC password, not the Linux login.

| Path | Role |
|---|---|
| `~/.vnc/passwd` | RFB password |
| `~/.vnc/config` | Optional default `vncserver` options |
| `~/.vnc/xstartup` | Session script (`exec startxfce4` on qin) |
| `~/.vnc/qin:N.log` | Xvnc log |
| `~/.vnc/qin:N.pid` | Xvnc PID |
| `~/.vnc/expire-N.stamp` | Lifetime for `vncstart` (`deadline=`, `display=`, `pid=`) |

## Connect from a laptop

Sessions are localhost-only. Tunnel the RFB port, then point the viewer at the local end.

```bash
# from the laptop, display :4 → local 5904
ssh -N -L 5904:127.0.0.1:5904 xcshen@HOST
```

`HOST` is the path you already use (ali reverse `127.0.0.1:22022`, or Tailscale `qin` / `100.88.248.51` / `qin.tail1fbc8b.ts.net`).

Viewer: `localhost:4` or `127.0.0.1:5904`. Prefer **VncAuth** (standard VNC password). VeNCrypt/TLSVnc often fails even when the session is healthy.

Health check on qin (banner, not only `nc -z`):

```bash
# healthy: RFB 003.008 then a security-type list
python3 - <<'PY'
import socket
s = socket.create_connection(("127.0.0.1", 5904), 3)
print(s.recv(12))
s.close()
PY
```

## DISPLAY in a terminal

GUI programs (IDL DE, matplotlib windows, etc.) need `DISPLAY` pointing at a live Xvnc.

```bash
vncwhich          # see which :N is up
vncuse 4          # DISPLAY=:4.0
echo $DISPLAY
```

VS Code terminals on qin try to pick a display automatically from an established 590x connection, then from `~/.vnc/*.log`, then from any `Xvnc`.

## Frequently used keywords

| Keyword | Meaning |
|---|---|
| **display** / **:N** | X/VNC session number. `:4` is display 4. |
| **port** / **5900+N** | RFB TCP port. `:4` → 5904. |
| **Xvnc** | The VNC X server process. |
| **vncserver** | Wrapper that starts/kills `Xvnc` and runs `xstartup`. |
| **vncstart** | qin helper: free `:N`, `-localhost yes`, 7-day (or longer) lifetime. |
| **vnckill** | qin helper: `vncserver -kill :N` plus remove expire stamp. |
| **vncpasswd** | Store the RFB password. |
| **localhost** | Bind 127.0.0.1 only; viewers must SSH-tunnel. |
| **geometry** | Desktop width×height (`1920x1080`). |
| **depth** | Bits per pixel, usually 24. |
| **RFB** | Remote Framebuffer protocol. Banner `RFB 003.008` is a live server. |
| **SecurityTypes** | Auth methods advertised to the viewer. |
| **VncAuth** | Classic DES password (type 2). Use this. |
| **VeNCrypt** / **TLSVnc** | TLS wrapper; often fails with common viewers on qin. |
| **xstartup** | Script that launches the desktop (`startxfce4`). |
| **session** | systemd/TigerVNC desktop name (`gnome` in distro defaults; qin xstartup uses XFCE). |
| **alwaysshared** | Allow more than one viewer at once. |
| **pidfile** | `~/.vnc/qin:N.pid`. |
| **expire stamp** | `~/.vnc/expire-N.stamp`; sweep kills the session after the deadline. |
| **long** | `vncstart` lifetime token = 60 days. |
| **vncserver.users** | Maps `:N` to a Linux user for systemd units. |
| **vncserver@:N** | systemd unit for a mapped display. |
| **X11-unix** | `/tmp/.X11-unix/XN`; if present, display `:N` is taken. |
| **DISPLAY** | `:`N`.0` for local X clients. |
| **XAUTHORITY** | X cookie file, usually `~/.Xauthority`. |
| **Too many security failures** | Xvnc lockout after failed logins; restart that display as its owner. |

## Quick checks

```bash
vncserver -list
pgrep -u "$USER" -af "Xvnc :"
ss -ltnp | grep 590
ls -l ~/.vnc/*.pid ~/.vnc/expire-*.stamp 2>/dev/null
```

Do not kill another user's `Xvnc`. Do not change `sshd_config`, Tailscale routing, or firewall to “fix” VNC; tunnel to localhost instead.
